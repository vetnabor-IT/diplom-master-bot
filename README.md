# Telegram Bot для заказа учебных работ

Бот для компании "ДипломМастер" - помогает пользователям заказывать рефераты, курсовые и дипломные работы.

## Функциональность

- 📋 Список услуг
- 💰 Расчет стоимости
- 📞 Обратная связь с менеджером
- 📱 Отправка номера телефона
